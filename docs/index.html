Open workflow engineering method · 1.1.1

Keep the boundary. Fix the motion.

A necessary constraint should guide completion, recovery, and handoff—not make people wrestle with the system around it.

Install the skill Challenge it with a case

Activation boundary

Workflow obstruction, not every constraint.

Use it

When a necessary safety, privacy, accessibility, ownership, compliance, or integrity boundary obstructs completion, recovery, handoff, or continuity.

Scale it

Use a compact pass for local reversible friction and a deeper trace when consequences, uncertainty, actors, or irreversibility increase.

Do not activate

For purely aesthetic critique, an ordinary requirement, or an isolated defect with no evidence of a broader workflow failure.
