# PPD-003 result boundary

Two implementation observations narrow interpretation without invalidating the
frozen comparison:

1. The harness executable reported Codex CLI `0.145.0`, while the combined
   session's internal `session_meta.cli_version` records `0.144.5`. The same
   executable and launch contract were used; the mismatch was discovered after
   execution and the arm was not rerun. Duration remains comparable, but the
   combined cumulative token counter should not be treated as directly
   commensurate with PPD-002 metadata.
2. A complete Superpowers export was not discovered until the isolated home
   included its normal `.agents/skills/superpowers` discovery link. The failed
   diagnostic produced no product result. The corrected diagnostic exposed
   exactly the two requested non-system packages before launch.

One Layer 3 evaluator transport accepted the prompt but produced no tool or
model output for twelve minutes. The prospective replacement rule was applied:
the invalid trace was preserved and a fresh session received the byte-identical
evidence. Only the replacement evaluation enters calculations.

These are harness and transport confounds, not evidence about the physical
product methods.
