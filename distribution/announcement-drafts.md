## OpenAI Developer Forum

**Category:** Community

**Title:** Fructal Cap Design: a tested skill for constrained workflow repair

Fructal Cap Design is an open Agent Skill for repairing workflow-level friction
without weakening the safety, privacy, accessibility, ownership, compliance,
interoperability, or data-integrity constraint that created the obstruction.

The skill was allowed to fail under a retained evaluator, and failed development
runs remain public. Natural execution and semantic judgment are separate
stages. The final 24-case matrix and 21 critical repetitions are reproducible,
but the evaluator is another isolated run of the same model family, so this is
not independent validation or scientific proof.

Install and run it from the public repository:
<https://github.com/PaolaShultz/shr-skills>

I would especially value cases that challenge activation, authorization, mode
boundaries, workflow continuity, retry, cancellation, and handoff behavior.
Please use the repository's adversarial-case issue form and do not include
secrets, personal data, proprietary material, or harmful content.

## Show HN

**Title:** Show HN: Fructal Cap Design – a tested Agent Skill for constrained workflows

**URL:** <https://github.com/PaolaShultz/shr-skills>

**Text:**

Fructal Cap Design is an open Agent Skill for workflow friction caused around a
necessary constraint. It supports Review, Redesign, and authorized Implement
work while preserving boundaries such as safety, privacy, accessibility,
ownership, compliance, interoperability, and data integrity.

You can install it directly from the repository. I kept the evaluation
falsifiable: the skill was allowed to fail, failed development runs remain in
the repository, and natural execution is separated from semantic judgment. The
final 24-case matrix and 21 critical repetitions are reproducible. The judge is
another isolated run of the same model family, so I am not claiming independent
validation, universal compatibility, or production acceptance.

I am looking for adversarial cases around activation, authorization, mode
boundaries, workflow continuity, retries, cancellation, and handoffs. The
repository includes a structured issue form for them.
