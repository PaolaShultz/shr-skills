# Fractal Cap Design 1.1.1

Version 1.1.1 tightens the behavioral contract without expanding its activation
scope. It:

- keeps Review read-only while allowing bounded recommendations when requested;
- distinguishes inspect-only reads from modification authority;
- requires confirmation only when the consequential action itself is requested
  and not already authorized;
- restores a clear acceptance gate after unavoidable interruption;
- scales depth with consequence, complexity, uncertainty, reversibility, and
  affected actors.

The retained release evidence contains a 24-case behavioral matrix and 21
critical repetitions. Failed development runs remain public alongside the
passing archives. The evaluator separates natural execution from semantic
judgment, but uses the same model family and is not independent validation.

This distribution package changes no 1.1.1 behavior. It wraps the canonical
skill in OpenAI and Claude plugin manifests and verifies the mirrored skill
byte-for-byte.
