# Listing assets

The SVG files are the original, editable Fractal Cap Design listing assets.
They use only vector geometry and system-font fallbacks. Raster derivatives
are generated from these sources and must not be edited as originals.

- <code>fractal-cap-icon.svg</code>: square icon, 512 by 512 view box.
- <code>fractal-cap-logo.svg</code>: horizontal wordmark, 1280 by 320 view box.
- <code>fractal-cap-icon-512.png</code>: 512 by 512 lossless listing derivative.
- <code>fractal-cap-logo-1280x320.png</code>: 1280 by 320 lossless listing derivative.
